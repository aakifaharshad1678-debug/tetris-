# Tetris Game

A classic Tetris-inspired game developed using **Java** and **ApacheNetBeans**.  
This project demonstrates fundamental game development concepts such as collision detection, piece rotation, line clearing, score tracking, and event handling.

## Features

- Classic Tetris gameplay
- Piece movement and rotation
- Line clearing mechanics
- Score tracking system
- Game Over screen

## Technologies Used

- Java
- Apache NetBeans

## How to Run

1. Clone or download this repository.
2. Open the project in **Apache NetBeans**.
3. Build the project.
4. Click **Run Project** (or press **F6**) to start the game.
